# 图案设计初稿

根据原图或主题画一张平涂设计稿，让主体缩小后仍然好认。

- 按取景要求从原图提取主体，先安排外形和背景。独立图案要让整个外形落在画幅内，四周留透明空间，主体内部的白色保留为实色。沿用原图可见的轮廓、角度和比例，按取景要求处理被原图边缘截断的部位。
