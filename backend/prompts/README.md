# 图案设计提示词

[视觉分析提示词](reference_analysis_prompt.md)接收原图或主题、用户要求、目标格数和本次的细节要求，并按 [JSON Schema](reference_analysis.schema.json)返回构图、保留项和简化项。

[生图模板](reference_generation_prompt.md)接收画幅比例、细节要求和具体画法。未设颜色上限时省略该行。ImageGen 根据原图和分析结果绘制平涂初稿，先落实主体外形和背景，再简化内部色块。独立图案先核对外形、留边和关键部位，再用目标格数生成图纸。

这些例子用于验证同一画法在不同制作尺寸下的细节密度。小尺寸例子把关键色带的宽度暂定为主体宽度的约二十五分之一，对应当前小板留边后主体约占二十五格。实际效果用落格后的预览验证。

| 目标尺寸 | 程序填入的细节要求 | 本案例的具体画法 |
| --- | --- | --- |
| 29×29 | 用极简平涂图标的画法。保留完整剪影和主要色块。关键线条的厚度至少约为主体宽度的二十五分之一。更细的线条并入相邻深色块，次要高光、阴影、纹理直接省略。 | 每只眼只用一块完整黄绿虹膜和一块宽深色竖瞳，左眼稍大；眼缘与周围深色形状合并，避免形成一圈独立细色带。额头保留两到三条粗纹，左脸颊保留两条粗纹。脸部用单一暖棕底色，口鼻和下巴合成一块浅色，鼻尖是一块砖红色。耳内各一块粉棕色。去掉鼻梁阴影、白色高光、须点和胡须。 |
| 48×48 | 主体占足面积，四周保留留边。对识别作用大的部位，先用主色和一两层有反差的色块表达光影或结构，关键边线画成有宽度的连续色带。 | 墨镜男孩与右下圆牌分别完整入画。发束用深棕底和顺着分缝的暖棕高光。两片镜片之间留清楚的暖棕镜桥，镜片留一小块亮色反光，嘴形用短而厚的深色块。杯盖、杯身和握杯的手用分得开的色块。裤腿用两三层蓝色定位膝盖和裤脚。圆牌只留蓝底和白色「李」。 |
| 58×58 | 保留大色块，在关键部位可以多留一层有辨识作用的颜色。表现清楚眼缘、虹膜和反光等次级区分，整理相近阴影和细碎纹理。 | 可以分开眼缘、竖瞳、虹膜与高光，保留耳内两层色和有代表性的脸颊条纹。 |
